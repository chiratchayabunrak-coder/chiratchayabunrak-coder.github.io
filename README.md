## 🌟 Overview (ภาพรวมโปรเจกต์)

โปรเจกต์นี้จัดทำขึ้นเพื่อพัฒนาโซลูชันด้านดิจิทัลสำหรับการศึกษา (EdTech) โดยเน้นการสร้าง Interactive User Experience ที่ส่งเสริมการเรียนรู้ มีฟีเจอร์หลักๆ ดังนี้:

- 📖 **Interactive Learning Modules:** บทเรียนและแบบฝึกหัดแบบโต้ตอบ
- 📊 **Progress Tracking:** ระบบติดตามพัฒนาการและการเรียนรู้ของผู้ใช้งาน
- 💻 **Responsive Design:** รองรับการใช้งานอย่างลื่นไหลบนทุกอุปกรณ์ (Desktop, Tablet, Mobile)
- ⚡ **High Performance:** ออกแบบและพัฒนาโดยคำนึงถึงความเร็วและความเสถียรของระบบ

## 🚀 Getting Started (เริ่มต้นใช้งาน)

สำหรับการติดตั้งและทดสอบโปรเจกต์นี้ในเครื่องของคุณ:

### Prerequisites
- Node.js (v18.0.0 ขึ้นไป)
- npm หรือ yarn

### Installation
1. Clone repository นี้ลงเครื่องของคุณ:
   ```bash
   git clone https://github.com/your-username/educational-app.git
   ```
2. เข้าไปที่โฟลเดอร์ของโปรเจกต์:
   ```bash
   cd educational-app
   ```
3. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
4. รันโปรเจกต์ใน Development mode:
   ```bash
   npm run dev
   ```
